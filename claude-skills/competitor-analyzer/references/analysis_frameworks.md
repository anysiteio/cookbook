## SaaS/API Products

### Key Focus Areas

**Business Model:**
- Usage-based vs subscription
- Free tier strategy
- Self-serve vs sales-led
- Land-and-expand approach

**Unit Economics:**
- Cost per API call/request
- Cost per seat/user
- Volume discount structure
- Overage charges

**Product-Market Fit Signals:**
- Organic user acquisition
- Customer retention metrics (if public)
- NPS/satisfaction scores
- Case study quality
- Review ratings (G2, Capterra)

### Analysis Template

```
## Pricing Analysis
- Entry price: $X/month
- Cost per unit: $Y per Z
- Free tier: X units/month
- Paid tiers: Starter ($A), Pro ($B), Enterprise (custom)
- Annual discount: X%

## GTM Strategy
- Self-serve: Yes/No
- Free trial: X days
- Primary acquisition: Docs, content, partnerships
- Sales team: Small/Large/None
- Typical deal size: $X-Y/month

## Product Velocity
- Changelog frequency: Weekly/Monthly
- Major features last 6mo: X
- API version: vX
- Last breaking change: Date

## Competitive Positioning
vs [Your Company]:
- Price: X% more/less expensive
- Features: Comparable/Superior/Inferior
- Ease of use: Better/Worse
- Documentation: Better/Worse
```

## Enterprise Software

### Key Focus Areas

**Enterprise Readiness:**
- SSO/SAML support
- SOC 2 compliance
- GDPR compliance
- SLA guarantees
- Dedicated support
- On-premise option
- Custom contracts

**Sales Process:**
- Sales cycle length (estimate from job postings)
- Demo requirement
- POC common?
- Implementation services
- Training offerings

**Customer Profile:**
- Typical company size
- Industries served
- Use cases featured
- Customer logo quality

### Analysis Template

```
## Enterprise Capabilities
- SSO: Yes/No
- Compliance: SOC 2, GDPR, HIPAA, etc.
- Uptime SLA: X%
- Support: Email/Phone/Dedicated
- Onboarding: Self-serve/Assisted/White-glove

## Sales Motion
- Cycle length: X months (estimated)
- Requires demo: Yes/No
- POC offered: Yes/No
- Implementation: X weeks
- Training: Included/Paid add-on

## Target Customer
- Company size: X-Y employees
- Industries: Primary, Secondary
- Buying persona: Title, Department
- Typical use case: Description

## Competitive Moat
- Switching costs: High/Medium/Low
- Integration depth: Surface/Deep
- Data lock-in: Yes/No
- Network effects: Yes/No
```

## Developer Tools

### Key Focus Areas

**Developer Experience:**
- Documentation quality
- Code examples
- SDKs available
- API design quality
- Time to first API call
- Debugging tools

**Community Engagement:**
- GitHub presence
- Stack Overflow activity
- Discord/Slack community
- Open-source components
- Community contributions
- Developer advocates

**Technical Depth:**
- Architecture explained
- Rate limits published
- Status page available
- API versioning strategy
- Deprecation policy

### Analysis Template

```
## Developer Experience Score

Documentation: X/10
- Completeness: Full/Partial
- Code examples: Many/Some/Few
- Interactive docs: Yes/No
- Tutorials: X available
- Time to hello world: X minutes

API Design: X/10
- RESTful: Yes/No
- Consistent: Yes/No
- Well-documented errors: Yes/No
- Pagination: Cursor/Offset/None
- Webhooks: Yes/No

SDKs: X/10
- Languages: Python, JS, Ruby, etc.
- Quality: Production-ready/Beta
- Examples included: Yes/No
- Type definitions: Yes/No

Community: X/10
- GitHub stars: X
- Active forum: Yes/No
- Response time: <Xh
- Community size: X developers

## Technical Positioning
- Architecture: [Description]
- Scalability claims: [Metrics]
- Performance: [Benchmarks if available]
- Reliability: [Uptime, SLA]

## Developer Acquisition
- Top of funnel: Docs, blog, GitHub
- Activation: Quick start guide
- First value: Within X minutes
- Expansion: [Path to paid]
```

## Consumer Apps

### Key Focus Areas

**User Acquisition:**
- App store presence (iOS/Android)
- App store ratings
- Download numbers (if available)
- Paid vs organic acquisition
- Referral program
- Social virality

**User Experience:**
- Onboarding flow
- Core feature accessibility
- Monetization approach
- Notification strategy
- Retention tactics

**Brand & Community:**
- Social media following
- User-generated content
- Community forums
- Brand personality
- Influencer partnerships

- Size: X MB

Android:
- Rating: X.X/5 (X reviews)

- Last update: X days ago

## User Acquisition
- Primary channel: Organic/Paid/Viral
- ASO quality: Strong/Weak
- Referral program: Yes/No
- Social proof: X followers
- PR coverage: Notable mentions

## Monetization
- Model: Freemium/Subscription/IAP/Ads

## Retention Strategy

## Brand Strength

## Cross-Category Considerations

### Pricing Psychology

**Premium Positioning:**
- High price point
- Emphasis on quality/exclusivity
- Enterprise-focused messaging
- "White-glove" services

**Value Positioning:**
- Competitive pricing
- Feature parity emphasis
- "X% cheaper than Y"
- Self-serve focus

**Freemium Strategy:**
- Generous free tier → viral growth
- Limited free tier → conversion focus
- Feature-gated → upsell path
- Usage-gated → expansion revenue

### Messaging Analysis

**Identify Primary Message:**
What's the ONE thing they want you to remember?

**Message Hierarchy:**
1. Primary message (hero headline)
2. Supporting messages (subheads)
3. Proof points (features, benefits)
4. Social proof (testimonials, logos)
5. Call to action

**Emotional vs Rational:**
- Rational: Facts, specs, comparisons
- Emotional: Transformation, relief, belonging
- Mix: Most effective positioning

### Competitive Threat Assessment

**High Threat:**
- Direct overlap in target market
- Similar pricing
- Better funded
- Growing faster
- Feature parity or advantage

**Medium Threat:**
- Adjacent market
- Different pricing tier
- Comparable resources
- Stable position

**Low Threat:**
- Different target market
- Significantly different pricing
- Stagnant or declining
- Different approach

## Output Formats

### Executive Summary (1 page)
- Company overview (2 sentences)
- Market position (1 paragraph)
- Strengths (3 bullets)
- Weaknesses (3 bullets)
- Strategic recommendation (1 paragraph)

### Battle Card (1-2 pages)
- Quick facts
- Head-to-head feature comparison
- Pricing comparison
- Win/loss analysis
- Talk tracks for sales

### Deep Dive Report (5-10 pages)
- All sections from analysis template
- Supporting data and screenshots
- Strategic implications
- Monitoring plan

### Competitive Matrix (spreadsheet)
- Features comparison across 5-10 competitors
- Pricing comparison
- Market position mapping
- Scoring methodology
